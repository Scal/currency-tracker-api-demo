# Currency Tracker API

Асинхронный REST API для получения курсов USD, EUR и CNY к рублю,
хранения истории и конвертации валют.

Источник данных — XML API Центрального банка России. При запуске приложение
получает курсы в фоне. После каждого обновления выдерживается пауза
600 секунд. Интервал настраивается через переменную окружения.
Каждое успешное получение сохраняет три записи в историю, даже если курсы
не изменились. При ошибке приложение записывает её в лог и повторяет попытку
после заданного интервала.

## Стек

- Python 3.12
- FastAPI, Pydantic v2 и Pydantic Settings
- PostgreSQL 17
- SQLAlchemy 2.0 async и asyncpg
- Alembic
- HTTPX
- Poetry
- Docker Compose

## Запуск

Требуются Git и Docker с поддержкой Linux-контейнеров и Docker Compose.
В Windows можно использовать Docker Desktop.

1. Склонируйте репозиторий и перейдите в папку проекта.
2. Создайте файл `.env` из `.env.example`.

   PowerShell:

   ```powershell
   Copy-Item .env.example .env
   ```

   Linux / macOS:

   ```bash
   cp .env.example .env
   ```

3. Задайте `POSTGRES_PASSWORD` в `.env`. Остальные значения можно оставить
   из примера. Для интервала по ТЗ используйте `UPDATE_INTERVAL_SECONDS=600`.
4. Запустите проект:

   ```bash
   docker compose up --build -d
   ```

Приложение дожидается готовности PostgreSQL, применяет миграции
командой `alembic upgrade head` и запускает Uvicorn.

Swagger UI: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

Порты 8000 и указанный в `POSTGRES_PORT` должны быть свободны.
Python и Poetry на компьютере для запуска через Docker не требуются.
Первое получение курсов выполняется в фоне: сразу после запуска база
может быть ещё пустой.

## Настройки

| Переменная | Назначение | Пример |
|---|---|---|
| `POSTGRES_DB` | Имя базы | `currency_tracker` |
| `POSTGRES_USER` | Пользователь базы | `currency_user` |
| `POSTGRES_PASSWORD` | Пароль базы | Задаётся в `.env` |
| `POSTGRES_HOST` | Адрес базы при запуске Python-приложения на компьютере | `localhost` |
| `POSTGRES_PORT` | Порт базы на компьютере | `5432` |
| `UPDATE_INTERVAL_SECONDS` | Пауза между обновлениями в секундах, минимум 1 | `600` |

Внутри Compose приложение подключается к `db:5432`: адрес и внутренний порт
переопределены в `docker-compose.yml`.
Файл `.env` не включается в Git и образ приложения.

## API

### Последние курсы

`GET /api/v1/rates/latest`

Возвращает последний сохранённый курс каждой из валют USD, EUR и CNY.
До первого успешного обновления возвращается пустой список.

### История курса

`GET /api/v1/rates/history?currency=USD&limit=10&offset=0`

- `currency` — обязательный код валюты: USD, EUR, CNY или RUB.
- `limit` — количество записей от 1 до 100, по умолчанию 10.
- `offset` — количество пропускаемых записей, минимум 0, по умолчанию 0.

Новые записи идут первыми. RUB в базе не хранится, его история пустая.
Каждая запись содержит `id`, `currency_code`, `rate` и `updated_at`.
Курс — стоимость одной единицы валюты в рублях. Поле `rate` передаётся
в JSON строкой для сохранения десятичного представления, время — в UTC.

### Конвертация

`POST /api/v1/convert`

Тело запроса:

```json
{
  "from_currency": "USD",
  "to_currency": "RUB",
  "amount": 100
}
```

Пример ответа при курсе USD 82.8879 RUB:

```json
{
  "result": 8288.79,
  "rate_used": 82.8879
}
```

Поддерживаются RUB, USD, EUR и CNY. Сумма должна быть неотрицательной.
Конвертация использует последние курсы из базы, без отдельного запроса к ЦБ.
Кросс-курс вычисляется через рубль. Расчёт выполняется с `Decimal`, результат
округляется до двух знаков по правилу `ROUND_HALF_UP`.
Поля ответа `result` и `rate_used` — JSON-числа.

Для одинаковых валют курс равен 1, обращение к базе не требуется.

Ошибки:

- `422` — некорректные входные данные, например неизвестная валюта,
  отрицательная сумма или `limit` вне допустимого диапазона.
- `503` — необходимые для конвертации курсы ещё не загружены.

## Управление контейнерами

Состояние:

```bash
docker compose ps
```

Логи приложения (выход из просмотра — Ctrl+C):

```bash
docker compose logs -f app
```

После изменения настроек `.env`:

```bash
docker compose up -d
```

После изменения кода:

```bash
docker compose up --build -d
```

Остановка и удаление контейнеров:

```bash
docker compose down
```

Данные PostgreSQL сохраняются в именованном volume `postgres_data`.
Команда `docker compose down -v` удаляет и этот volume вместе с данными базы.
Изменение пароля в `.env` не меняет пароль пользователя уже созданной базы.
